I want you to make an application that can open .h5 files. The application should let the user view the file group hierarchy and datasets. The application should have a left-side pane where the group hierarchy can be viewed, expanded and collapsed; similar to the directory/explorer view in VSCode and similar. To the right of the left pane is where the main content should go. Once the user selects a dataset from the left side pane, the main content should fill with a table view of the selected dataset. Selecting a different dataset should replace the currently selected one. The application should be written in python, using CustomTkinter, with a well thought out and proper project setup, using venv and requirements.txt, and use the h5py library for reading and manipulating the h5 file. The application should look modern, sleek, follow system dark/light mode, and should feel responsive. I suspect that means that you will have to consider how to render datasets, considering these might get big. The dataset table view should use different colors for coloums to make it easier to differentiate between columns when scrolling down the dataset. The dataset view should not be "paginated" but allow for continous scrolling untill the end of the dataset (but loading only a part of the dataset currently being viewed might be necessary, figure it out).
